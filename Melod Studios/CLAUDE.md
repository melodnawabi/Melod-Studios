# Melod Studios site — standing rules
- Every client build carries a "Built by Melod Studios" credit, bottom-right of every page, non-negotiable.
- That credit always links to the Melod Studios website (this site). Domain not live yet — use placeholder [MELOD STUDIOS URL] (href "#top" in demos) and swap once the domain exists.
- Removal of the credit is a paid fee, only mentioned when the client asks. Never show the fee on the site.
- Every build checks MotionSites (https://motionsites.ai/) for motion and section ideas: animated hero backgrounds, 3D scenes, feature, pricing, CTA and footer patterns. Use it for inspiration only. Rebuild each idea as original work in the client's brand, and never copy its prompts, assets or designs verbatim, since they are paid and copyrighted.
- Every build uses Unsplash (https://unsplash.com/) for photos when the client has none. Pick shots that match the client's business and city, use them under the Unsplash License, credit the photographer where it fits, and swap in the client's real photos when they arrive.
- Every build checks Webflow Templates (https://webflow.com/templates) for layout and section ideas, for inspiration only. Rebuild each idea as original work, and never copy a template's design or assets.
- Template ideas also come from Billion Dollar Design (https://billiondollardesign.com/), Framer's Billions template (https://www.framer.com/marketplace/templates/billions/) and Figma Community business templates (https://www.figma.com/community/website-templates/business). Inspiration only: rebuild as original work, never copy layouts, copy or assets. A Figma Community file may be reused only if its listed licence allows commercial use, with credit where required.
- Client-facing copy describes tool categories (design, motion, speed, search, hosting, forms) and their benefits. Never name the specific tools or inspiration sources on client-facing pages, except as plain text on the Resources page.
- No outbound links to other people's sites, anywhere. The only external links allowed are melodnawabi.ca and Melod Studios client projects (e.g. garynagramortgages.ca).
- Menu names: Work, Templates, Pricing, Our story, Resources, plus the "Get in touch" button.
- Fonts: start with Google Fonts (https://fonts.google.com/), which are free for commercial use. Use Slickfish's guide (https://slickfish.com/web-design/best-free-web-fonts-for-web-design) for pairing ideas. Use FontSpace (https://www.fontspace.com/) for display faces only when the licence allows commercial use, since many are personal-use only. Confirm the licence before a font goes into a client build.
- Build process follows the Wix 10-step guide (https://www.wix.com/blog/how-to-build-website-from-scratch-guide) as a checklist: purpose and audience, domain, hosting, design, sitemap (any page within 3 clicks), essential pages (home, services, about, contact, plus FAQ, testimonials, 404), content above the fold, accessibility (alt text, contrast, 16px+ body, keyboard reachable), test on phones and browsers, launch, then maintain. Use it as a reference only; never copy its text.
- Squarespace (https://www.squarespace.com/) is a polish benchmark for clean layouts, big imagery and simple navigation. Inspiration only; never copy its templates or assets.
- Lighthouse is required on every build. Run it on mobile before launch. Target 90+ in Performance, Accessibility, Best Practices and SEO, and aim for under 3 seconds load on a phone connection. Fix anything under 90 before go-live and keep the report for the client.
- Ahrefs is the SEO check on every build. Before launch, run a site audit with Ahrefs Webmaster Tools (https://ahrefs.com/webmaster-tools, free once the site is verified) and fix broken links, missing titles, descriptions and alt text. Use Ahrefs' free tools (https://ahrefs.com/free-seo-tools) for keyword ideas and backlink checks. After launch, recheck monthly for Hands on Plus clients.
- Stack: Cloudflare for domains (Registrar at cost), DNS, SSL and CDN, with Cloudflare Pages for static sites. Firebase for anything dynamic: Hosting, Auth, Firestore for form and booking data, and Functions for email and lead routing. Default to Cloudflare Pages and add Firebase only when the site needs a backend.
- easyDNS (https://easydns.com/) is not part of the default stack. Use it only when a client already has DNS there (keep it and point records at Cloudflare Pages) or asks for a Canadian-run provider. Its servers are worldwide, so never pitch it as keeping data in Canada.
